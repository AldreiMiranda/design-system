## Instalação

```bash
npm install @aldreimiranda/design-system
```

Importe os componentes e os estilos uma única vez na aplicação:

```tsx
import { Button, TextField } from '@aldreimiranda/design-system';
import '@aldreimiranda/design-system/styles.css';

export function Formulario() {
  return (
    <form>
      <TextField label="E-mail" type="email" />
      <Button type="submit">Continuar</Button>
    </form>
  );
}
```

## Princípios

1. **Consistência antes de personalização:** reutilize padrões existentes antes de criar variações.
2. **Semântica antes de aparência:** escolha o elemento correto e aplique a variante visual necessária.
3. **Acessibilidade como requisito:** estados, foco e mensagens devem funcionar para todas as pessoas.
4. **APIs pequenas e previsíveis:** os componentes estendem os atributos nativos sempre que possível.
